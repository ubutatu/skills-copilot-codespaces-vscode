# Contributing to GitHub Copilot Enterprise Compliance Pro

Thank you for your interest in contributing to this course!

## Code of Conduct

This project and everyone participating in it is governed by the [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How to Contribute

1. **Reporting Bugs**: If you find a bug in the course material or automation, please open an issue.
2. **Suggesting Enhancements**: We welcome ideas for new compliance topics or improvements to existing ones.
3. **Pull Requests**:
   - Fork the repository.
   - Create a new branch for your changes.
   - Ensure your changes follow the existing style and structure.
   - Submit a pull request with a clear description of your changes.

## Security Vulnerabilities

Please do not report security vulnerabilities via public issues. See [SECURITY.md](SECURITY.md) for instructions on how to report security concerns.
