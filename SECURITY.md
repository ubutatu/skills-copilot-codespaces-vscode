# Security Policy

## Supported Versions

The following versions of this course are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately. Do not open a public issue.

Please report security vulnerabilities via the [GitHub Vulnerability Reporting](https://github.com/skills/code-with-copilot/security/advisories/new) feature or by following the standard GitHub security procedures.

We will acknowledge your report and provide a timeline for addressing the issue.
